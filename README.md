# Product Card UI

A clean, modern and responsive product card design with a dark theme.
It has a split layout: content on the left, a product image on the right.

## Features
- Dark theme with a clean layout
- Heading, description and key stats (Comments, Paid Users, Views)
- Image section with a modern look
- Fully responsive
- Easy to customize for any online store

## Tech Stack
- HTML5
- CSS3
